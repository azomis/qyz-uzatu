# Азиза — онлайн-приглашение на «Кыз узату»

Одностраничный статический сайт-приглашение на торжество «Кыз узату» (Қыз ұзату).
Без фреймворков и сборщиков: HTML + CSS + ванильный JS. Ответы гостей сохраняются в Google Таблицу через Google Apps Script.

## Возможности

- **Три языка**: казахский (по умолчанию), русский, английский. Переключатель на видном месте; выбор запоминается в `localStorage` и в параметре `?lang=kk|ru|en`.
- **Адаптивная вёрстка**: мобильные, планшеты, десктоп.
- **Экран-«занавес»** с кнопкой «Открыть приглашение»: блокирует прокрутку, по нажатию открывает сайт и запускает музыку (браузеры не разрешают автозапуск звука без действия пользователя).
- **Анимации появления** блоков, орнаменты (шанырак, тұмар, домбра, тюльпан) в виде inline SVG.
- **Обратный отсчёт** до начала торжества (дни / часы / минуты / секунды).
- **Календарь** марта 2027 с отметкой даты и кнопки «Добавить в календарь»: Google Calendar и файл `.ics` (iOS / Android / Apple Calendar), с напоминанием за сутки.
- **Цветовая палитра** торжества (дресс-код как пожелание).
- **RSVP-форма**: ФИО, выбор «приду / не приду», необязательные пожелания; защита-ловушка от ботов (honeypot); ответ уходит в Google Таблицу.
- **Фоновая музыка** с кнопкой включения / выключения.

## Быстрый старт

Нужен только Python 3 (стандартная библиотека, зависимостей нет).

### Запуск локально

Сайт статический, подойдёт любой статический сервер:

```bash
cd /Users/a.omirgaliyeva/aziza
python3 -m http.server 8000 --bind 0.0.0.0
```

- Компьютер: http://localhost:8000
- Телефон в той же Wi-Fi сети: `http://<IP компьютера>:8000` (IP: `ipconfig getifaddr en0`)

### Внесение правок

`index.html` собирается из `src/index.src.html`, поэтому правим исходник и пересобираем:

```bash
cd src && python3 build.py
```

Скрипт запускать **из папки `src/`**, так как пути в нём относительные. Тексты и переводы лежат в объекте `I18N` в `js/app.js`; разметка и стили (включая CSS-переменные палитры) — в `src/index.src.html`.

## Настройка

Все параметры в блоке `CONFIG` в начале [js/app.js](js/app.js):

| Параметр | Назначение |
|---|---|
| `RSVP_URL` | URL развёрнутого Apps Script Web App. Если пусто, форма работает в демо-режиме: ответы остаются только в `localStorage` |
| `EVENT_START` / `EVENT_END` | Начало и конец события в ISO 8601 со смещением, сейчас `2027-03-21T13:00:00+05:00` / `2027-03-21T22:00:00+05:00` |
| `DEFAULT_LANG` | Язык по умолчанию (`kk`) |

Адрес для календарных событий задан константой `LOCATION` там же. При смене даты или места нужно обновить также тексты в `I18N` и `src/index.src.html`, затем пересобрать страницу.

### Цветовая палитра

Задана CSS-переменными в `src/index.src.html` (`:root`): `--wine`, `--berry`, `--mauve`, `--ivory`, `--sage`, `--olive`, `--mist`, `--moss` и их светлые варианты с суффиксом `-s`.

## Сохранение ответов гостей (Google Apps Script)

1. Создать Google Таблицу: **Расширения → Apps Script**, вставить содержимое [apps-script/Code.gs](apps-script/Code.gs).
2. **Развёртывание → Новое развёртывание → Веб-приложение**: «Выполнять от имени» — я, «Доступ» — все.
3. Скопировать URL веб-приложения в `CONFIG.RSVP_URL` в `js/app.js`.
4. После любого изменения `Code.gs` создавать **новую версию** развёртывания.

Проверка: открыть URL веб-приложения в браузере, в ответе будет `RSVP endpoint is up · version …`. Тест записи без формы: запустить `testDoPost` из редактора.

Скрипт при первой записи создаёт лист `RSVP` со столбцами: время получения, ФИО, ответ, язык, время отправки (клиент), пожелания. Имя ограничено 120 символами, пожелания — 1000; значения, начинающиеся с `=`, `+`, `-`, `@`, экранируются от инъекции формул.

> Примечание: в шапке `Code.gs` путь указан как `shared/app.js`, актуальный путь — `js/app.js`.

## Публикация

Для публикации достаточно выложить содержимое папки как есть (`index.html`, `js/`, `assets/`, `fonts/`) на любой статический хостинг. Папки `src/`, `apps-script/` и `.claude/` на сайте не нужны.

Перед публикацией стоит проверить:

- `RSVP_URL` указывает на актуальное развёртывание Apps Script;
- `index.html` пересобран после последних правок в `src/`;
- музыка стартует по нажатию «Открыть приглашение» на iOS и Android.
